Help - Taxonomy Admin Panel

Getting Started

Use this admin panel to manage taxonomy hierarchies for Macrobenthos, Zooplankton, and Phytoplankton specimen types.

Managing Taxa

  • Add Root Taxon: Create a top-level taxon (e.g., Phylum)
  • Add Child: Hover over a taxon and click "+ Child" to add sub-taxa
  • Edit: Click on any taxon to edit its details
  • Delete: Select a taxon and click Delete (must have no children)

CSV Import Format

Import taxa in bulk using CSV files with the following columns:

ColumnRequiredDescription
idYesUnique numeric ID for the taxon
parentIdNoID of parent taxon (empty for root taxa)
nameYesName of the taxon
rankYesTaxonomic rank (see valid ranks below)
notesNoOptional notes or description

Valid Ranks

Macrobenthos & Zooplankton: Phylum, Class, Order, Family, Genus, Species

Phytoplankton: Division, Class, Order, Family, Genus, Species
