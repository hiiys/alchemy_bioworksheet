Help - Taxonomy Admin Panel

Getting Started

Use this admin panel to manage taxonomy hierarchies for Macrobenthos, Zooplankton, and Phytoplankton specimen types.

Managing Taxa

  • Add Root Taxon: Create a top-level taxon (e.g., Phylum)
  • Add Child: Hover over a taxon and click "+ Child" to add sub-taxa
  • Edit: Click on any taxon to edit its details
  • Delete: Select a taxon and click Delete (must have no children)

CSV Import Formats

The system supports two CSV import formats. The format is automatically detected.

Format 1: Standard Format (with parent-child relationships)

Use this format when you want explicit control over the hierarchy:

ColumnRequiredDescription
idYesUnique numeric ID for the taxon
parentIdNoID of parent taxon (empty for root taxa)
nameYesName of the taxon
rankYesTaxonomic rank (see valid ranks below)
notesNoOptional notes or description

Example: id,parentId,name,rank,notes

Format 2: Hierarchical Format (automatic hierarchy)

Use this format to automatically build the taxonomy hierarchy. IDs and parent-child relationships are created automatically:

ColumnRequiredDescription
Taxa_IDNoOptional reference ID (not used in database)
PhylumYes*Phylum name
ClassYes*Class name
OrderYes*Order name
FamilyYes*Family name
GenusYes*Genus name
SpeciesNoSpecies name (optional)

*At least one taxonomic rank must be provided. Empty cells are skipped.

Example: Taxa_ID,Phylum,Class,Order,Family,Genus

Note: The hierarchical format automatically prevents duplicates and builds proper parent-child relationships.

Valid Ranks

Macrobenthos & Zooplankton: Phylum, Class, Order, Family, Genus, Species

Phytoplankton: Division, Class, Order, Family, Genus, Species
