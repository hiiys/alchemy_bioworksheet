================================================================================
    HOW TO CONVERT WORKPLAN TO .DOCX FOR PRINTING
================================================================================

You have 3 files in this folder:

1. FIREBASE_IMPLEMENTATION_WORKPLAN.md  (The work plan - source file)
2. convert_to_docx.bat                   (Automatic converter - double-click)
3. convert_to_docx.ps1                   (PowerShell version - alternative)

================================================================================
    METHOD 1: AUTOMATIC CONVERSION (EASIEST)
================================================================================

STEP 1: Double-click "convert_to_docx.bat"

STEP 2: The script will:
   - Check for Pandoc (conversion tool)
   - If found: Convert automatically
   - If not found: Show manual instructions

STEP 3: If successful:
   - File "FIREBASE_WORKPLAN.docx" will be created
   - It will open automatically in Word
   - You can now print it!

================================================================================
    METHOD 2: MANUAL CONVERSION WITH MICROSOFT WORD
================================================================================

STEP 1: Open Microsoft Word

STEP 2: Click "File" → "Open" (or press Ctrl+O)

STEP 3: Navigate to this folder:
   C:\dev\claude\biological_worksheets\

STEP 4: At the bottom of the Open dialog:
   - Change file type filter from "Word Documents (*.docx)"
   - To: "All Files (*.*)"

STEP 5: Select the file:
   FIREBASE_IMPLEMENTATION_WORKPLAN.md

STEP 6: Click "Open"
   - Word will automatically convert the markdown
   - You'll see the formatted document

STEP 7: Save as .docx:
   - Click "File" → "Save As"
   - Choose location
   - Make sure format is "Word Document (*.docx)"
   - Click "Save"

STEP 8: Print!
   - File → Print
   - Recommended: Two-sided printing to save paper
   - Estimated pages: 60-70 pages

================================================================================
    METHOD 3: INSTALL PANDOC FOR BEST RESULTS
================================================================================

Pandoc creates better-formatted documents with automatic table of contents.

STEP 1: Install Pandoc

   Option A - Download Installer (Easiest):
      1. Go to: https://pandoc.org/installing.html
      2. Click "Download the latest installer"
      3. Run the installer (pandoc-3.x-windows-x86_64.msi)
      4. Follow installation prompts
      5. Restart your computer

   Option B - Using Chocolatey (if you have it):
      1. Open PowerShell as Administrator
      2. Run: choco install pandoc
      3. Wait for installation to complete

STEP 2: Convert using Pandoc

   Option A - Use the batch file:
      1. Double-click "convert_to_docx.bat"
      2. Pandoc will now be detected
      3. Conversion happens automatically

   Option B - Manual command:
      1. Open PowerShell or Command Prompt
      2. Navigate to this folder:
         cd C:\dev\claude\biological_worksheets
      3. Run this command:
         pandoc FIREBASE_IMPLEMENTATION_WORKPLAN.md -o FIREBASE_WORKPLAN.docx --toc
      4. Done! Open FIREBASE_WORKPLAN.docx

================================================================================
    METHOD 4: ONLINE CONVERSION (NO INSTALLATION)
================================================================================

STEP 1: Go to online converter:
   https://cloudconvert.com/md-to-docx

STEP 2: Click "Select File"

STEP 3: Navigate to and select:
   C:\dev\claude\biological_worksheets\FIREBASE_IMPLEMENTATION_WORKPLAN.md

STEP 4: Click "Convert"

STEP 5: Wait for conversion (usually 10-30 seconds)

STEP 6: Click "Download" button

STEP 7: Open the downloaded .docx file

STEP 8: Print!

================================================================================
    TROUBLESHOOTING
================================================================================

Problem: "Cannot find file"
Solution: Make sure you're in the correct directory:
          C:\dev\claude\biological_worksheets\

Problem: "Pandoc not found"
Solution: Either install Pandoc (Method 3) or use Word directly (Method 2)

Problem: "Word won't open .md file"
Solution: Make sure you changed the file filter to "All Files (*.*)" in the
          Open dialog

Problem: "Document looks unformatted"
Solution: Use Pandoc (Method 3) for best formatting, or manually apply
          Word styles to headings after opening

Problem: "Script won't run"
Solution: Right-click convert_to_docx.bat → "Run as Administrator"
