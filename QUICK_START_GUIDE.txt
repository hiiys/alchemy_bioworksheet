================================================================================
                         STEP-BY-STEP (5 MINUTES)
================================================================================

STEP 1: Open Microsoft Word
   ├─ Click Start Menu
   ├─ Type "Word"
   └─ Click "Microsoft Word"

STEP 2: Open the Markdown File
   ├─ In Word, press Ctrl+O (or click File → Open)
   ├─ Click "Browse"
   └─ Navigate to: C:\dev\claude\biological_worksheets\

STEP 3: Change File Filter ⚠️ IMPORTANT!
   ├─ Look at bottom-right of Open dialog
   ├─ You'll see a dropdown that says "Word Documents (*.docx)"
   ├─ Click on it
   └─ Select "All Files (*.*)"

   Now you'll see the .md file!

STEP 4: Select the File
   └─ Click on: FIREBASE_IMPLEMENTATION_WORKPLAN.md

STEP 5: Click "Open"
   └─ Word will automatically convert it to a formatted document!

   ⏱️ This takes 5-10 seconds

STEP 6: Save as .docx
   ├─ Press Ctrl+S (or click File → Save As)
   ├─ Choose where to save (same folder is fine)
   ├─ Name it: FIREBASE_WORKPLAN
   ├─ Make sure format is: Word Document (*.docx)
   └─ Click "Save"

STEP 7: Print! 🖨️
   ├─ Press Ctrl+P (or click File → Print)
   ├─ Settings:
   │  ├─ Two-sided: Yes (saves paper!)
   │  ├─ Color: Black & White is fine
   │  └─ Pages: All (or select specific pages)
   └─ Click "Print"

   📄 Total pages: ~60-70 pages
   💰 Cost: ~$3-5 if using print shop

================================================================================
                         TROUBLESHOOTING
================================================================================

❓ "I don't see the .md file when I click Open in Word"
   → Make sure you changed the file filter to "All Files (*.*)"

❓ "The automatic script doesn't work"
   → Just use the manual Word method above - it's actually faster!

❓ "Word shows weird formatting"
   → That's normal - Word converts markdown automatically
   → Save it as .docx and it will look better

❓ "I want better formatting with table of contents"
   → Install Pandoc: https://pandoc.org/installing.html
   → Then double-click convert_to_docx.bat

❓ "I don't have Microsoft Word"
   → Use Google Docs (File → Open → Upload .md file)
   → Or LibreOffice Writer (free alternative)
   → Or online converter: https://cloudconvert.com/md-to-docx
